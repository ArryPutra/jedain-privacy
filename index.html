JedaIn: Stop Doomscrolling

Terakhir diperbarui: 3 November 2026

1. Pendahuluan

JedaIn menghargai privasi pengguna. Kebijakan Privasi ini menjelaskan bagaimana aplikasi JedaIn mengakses, menggunakan, dan menyimpan informasi yang diperlukan untuk menyediakan fitur pemantauan waktu layar dan pengelolaan sesi jeda.

2. Informasi yang Diakses oleh Aplikasi

Untuk menjalankan fungsinya, JedaIn dapat mengakses informasi berikut melalui izin Android yang diberikan oleh pengguna:

  • Informasi penggunaan aplikasi: informasi durasi penggunaan aplikasi yang dipantau melalui izin Usage Access.
  • Informasi aplikasi terpasang: informasi aplikasi yang tersedia di perangkat untuk membantu pengguna memilih aplikasi yang ingin dipantau.
  • Preferensi pengguna: target waktu layar, daftar aplikasi yang dipantau, serta pengaturan dan sesi jeda.

3. Cara Informasi Digunakan

Informasi tersebut digunakan hanya untuk mendukung fitur JedaIn, termasuk:

  • Menampilkan durasi penggunaan aplikasi.
  • Membandingkan penggunaan dengan target waktu layar.
  • Menjalankan pengingat dan penghitung waktu penggunaan.
  • Mengelola sesi jeda dan preferensi pengguna.

4. Penyimpanan Data

Berdasarkan implementasi aplikasi saat ini, informasi penggunaan dan preferensi JedaIn diproses serta disimpan secara lokal di perangkat pengguna. JedaIn tidak mengoperasikan akun pengguna atau server penyimpanan data pribadi untuk fitur-fitur tersebut.

5. Pembagian Informasi

JedaIn tidak menjual, menyewakan, atau membagikan informasi penggunaan aplikasi maupun preferensi pengguna kepada pihak ketiga untuk tujuan pemasaran.

6. Koneksi Internet

Fitur inti JedaIn dirancang untuk memproses informasi penggunaan secara lokal di perangkat. Jika versi aplikasi mendatang menggunakan layanan pihak ketiga atau koneksi jaringan untuk fitur tambahan, kebijakan ini akan diperbarui sesuai perubahan tersebut.

7. Izin Aplikasi

JedaIn dapat memerlukan izin Android berikut:

  • Usage Access: untuk membaca statistik penggunaan aplikasi yang diperlukan oleh fitur pemantauan waktu layar.
  • Display over other apps: untuk menampilkan penghitung waktu mengambang di atas aplikasi lain.
  • Foreground Service: untuk mendukung proses pemantauan yang perlu berjalan ketika aplikasi tidak sedang dibuka.
  • Notifications: untuk menampilkan pengingat dan informasi terkait sesi pemantauan atau jeda.

Pengguna dapat mengelola atau mencabut izin tersebut melalui pengaturan perangkat Android. Beberapa fitur JedaIn mungkin tidak berfungsi jika izin yang diperlukan dicabut.

8. Penghapusan Data

Pengguna dapat menghapus data lokal JedaIn melalui pengaturan aplikasi Android dengan memilih opsi hapus data atau dengan menghapus instalasi aplikasi. Tindakan tersebut dapat menghapus preferensi dan pengaturan yang tersimpan di perangkat.

9. Privasi Anak

JedaIn bukan aplikasi yang secara khusus ditujukan kepada anak-anak. Kami tidak secara sengaja mengumpulkan informasi pribadi anak melalui server.

10. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui apabila terdapat perubahan pada fitur, teknologi, atau praktik pengelolaan informasi JedaIn. Versi terbaru akan dipublikasikan melalui halaman ini.

Privacy Policy

JedaIn: Stop Doomscrolling

1. Introduction

JedaIn respects your privacy. This Privacy Policy explains how JedaIn accesses, uses, and stores information necessary to provide screen time monitoring and break management features.

2. Information Accessed by the App

To provide its functionality, JedaIn may access the following information through Android permissions granted by the user:

  • App usage information: usage duration information for monitored applications through Usage Access.
  • Installed application information: information about applications available on the device so users can select which applications to monitor.
  • User preferences: screen time targets, monitored application lists, and break session settings.

3. How Information Is Used

This information is used to support JedaIn features, including:

  • Displaying application usage duration.
  • Comparing usage against screen time targets.
  • Running reminders and usage timers.
  • Managing break sessions and user preferences.

4. Data Storage

Based on the current app implementation, usage information and preferences are processed and stored locally on the user's device. JedaIn does not operate user accounts or a personal data storage server for these features.

5. Information Sharing

JedaIn does not sell, rent, or share application usage information or user preferences with third parties for marketing purposes.

6. Internet Connectivity

JedaIn's core features are designed to process usage information locally on the device. If future versions use third-party services or network connections for additional features, this policy will be updated accordingly.

7. App Permissions

JedaIn may require the following Android permissions:

  • Usage Access: to read application usage statistics required for screen time monitoring.
  • Display over other apps: to display a floating timer over other applications.
  • Foreground Service: to support monitoring processes that need to run while the app is not open.
  • Notifications: to display reminders and information related to monitoring or break sessions.

Users can manage or revoke these permissions through their Android device settings. Some JedaIn features may not work if required permissions are revoked.

8. Data Deletion

Users can delete JedaIn's local data through Android app settings by selecting the clear data option, or by uninstalling the app. These actions may remove locally stored preferences and settings.

9. Children's Privacy

JedaIn is not specifically designed for children. We do not knowingly collect children's personal information through a server.

10. Changes to This Privacy Policy

This Privacy Policy may be updated if there are changes to JedaIn's features, technology, or information handling practices. The latest version will be published on this page.
