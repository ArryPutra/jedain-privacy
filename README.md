# Privacy Policy – JedaIn

**Last updated: November 3, 2026**

## 1. Introduction

JedaIn ("we", "our", or "the app") is a digital wellbeing application designed to help users manage screen time, monitor selected applications, and develop healthier digital habits.

We respect your privacy. JedaIn is designed to operate locally on your Android device. We do not operate a server to collect or store your screen time information.

## 2. Information Accessed by the App

JedaIn accesses certain information only to provide its core functionality:

**Application Usage Statistics**

JedaIn uses Android Usage Access permission to measure screen time, identify active applications, and calculate usage durations.

**Installed Applications**

JedaIn accesses information about applications with launcher icons so users can select which applications they want to monitor.

**User Preferences**

JedaIn stores settings such as daily screen time targets, monitored applications, break durations, and session information.

## 3. How We Use Information

The information accessed by JedaIn is used exclusively to:

- Display daily screen time statistics.
- Monitor applications selected by the user.
- Display floating screen time indicators.
- Manage break sessions and countdown timers.
- Provide reminders and screen time awareness features.

## 4. Local Data Storage

JedaIn stores application settings and session information locally on the user's Android device using Android SharedPreferences.

Screen time calculations are performed locally using Android's UsageStatsManager API.

JedaIn does not transmit this information to external servers.

## 5. Data Sharing

JedaIn does not sell, rent, or share users' application usage information with advertisers or third parties.

The application does not currently integrate advertising, analytics, or third-party crash reporting SDKs.

## 6. Internet Connectivity

JedaIn does not request the Android INTERNET permission in its current implementation.

Its core screen time monitoring and break management functionality operates locally on the device.

## 7. Permissions

JedaIn may request the following Android permissions:

- **Usage Access:** To read application usage statistics and calculate screen time.
- **Display Over Other Apps:** To display floating timers and reminders over other applications.
- **Foreground Service:** To maintain the screen time monitoring service while the application is running in the background.
- **Notifications:** To display service notifications and break reminders.

These permissions are used to provide the application's functionality.

## 8. Data Retention and Deletion

Application preferences and session information are stored locally on your device.

You can remove locally stored application data through Android Settings by clearing JedaIn's app storage or by uninstalling the application.

## 9. Children's Privacy

JedaIn is not specifically designed to collect personal information from children. The application does not require users to create an account or provide personal information.

## 10. Changes to This Privacy Policy

We may update this Privacy Policy when application features or privacy practices change.

Any updates will be published on this page with a revised update date.
